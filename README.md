# Akıllı Tatil Planlama ve Bütçe Kontrol Sistemi

Python ile yazılmış, terminal üzerinden çalışan bir tatil planlama uygulaması.
Kullanıcıdan tatil bilgilerini alır, toplam maliyeti hesaplar, bütçenin yeterli
olup olmadığını kontrol eder ve tatil planına puan verir.

## Özellikler

- Otel, ulaşım ve yemek maliyetlerinin ayrı ayrı hesaplanması
- Yaşa göre indirim (0-6 yaş %50, 7-18 yaş %20, 65+ %30)
- Uzun tatil indirimi (7 gün ve üzeri %10)
- Grup indirimi (3-4 kişi %5, 5+ kişi %10)
- Bütçe kontrolü ve kalan paraya göre yorum
- Hava durumuna ve şehre göre etkinlik önerisi
- Tatil planına 100 üzerinden puanlama
- Tatil özetinin sözlük yapısında saklanması

## Kullanılan Konular

Liste, tuple, set, sözlük veri yapıları; if/elif/else koşulları, iç içe
koşullar, mantıksal operatörler (and, or), matematiksel işlemler.

## Çalıştırma

```
python tatil_planlama.py
```
